# Boomerang

Адаптивный сайт SPA-студии «Место SPA» с каталогом программ и формой заявки. Построен на Next.js, React и TypeScript.

Опубликованный сайт: [Место SPA](https://rainbow-glyph-hh276hs.shipstatic.com/).

## Разработка

Требуется Node.js 22.18 или новее. Рекомендуется Node.js 24 (см. `.nvmrc`).

```sh
npm ci
npm run dev
```

Сайт доступен по адресу http://localhost:3000.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## Сборка

`npm run build` создаёт статическую версию в `out/`. Содержимое этой папки можно разместить на статическом хостинге. Сервер Node.js для публикации не требуется.

## Возможности

- Выбор SPA-программы с длительностью и стоимостью.
- Адаптивная навигация и анимации с учётом настройки уменьшения движения.
- Проверка имени, программы и желаемой даты; прошедшие и некорректные даты отклоняются.
- Сохранение последней заявки в браузере, восстановление после обновления и редактирование.
- Обработка повреждённых сохранений и ошибок доступа к хранилищу браузера.

Форма сохраняет данные только в localStorage и не отправляет заявку в студию. Серверная обработка, платежи и CRM не подключены.

## Настройка

Программы задаются в `lib/booking.ts`, изображения и описания карточек — в `components/projects.tsx`. Адрес студии и карта настраиваются в `components/call-to-action.tsx`; текущий адрес — Москва, ул. Покровка, 27. Карта использует Яндекс Карты.
